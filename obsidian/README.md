# Obsidian 标签配色

将 `fangtang-tags.css` 放入目标知识库的 `.obsidian/snippets/`，然后在 Obsidian → 设置 → 外观 → CSS 代码片段中刷新并启用 `fangtang-tags`。

SOP 蓝、技巧绿、案例橙、观点紫、灵感玫红、待整理灰。浅色与深色模式分别配置前景和底色，保留文字标签帮助辨识。

仅影响这六个同名标签，在当前知识库的所有笔记中生效；不改变原始 Markdown、标签点击与搜索、字号、PopClip 操作栏或其他标签。阅读视图与实时预览使用各自的选择器。其他设备需同步样式并启用。

`方糖标签配色.md` 可作为六种颜色的预览笔记。回退只需在设置中关闭该 CSS 片段。
